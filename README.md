# Brave Motors — сайт

Одностраничный сайт компании Brave Motors (пригон авто под ключ). Готов к публикации на GitHub Pages: сборка не нужна.

## Состав

- `index.html` — страница
- `styles.css` — стили и анимации
- `app.js` — вся логика (без сторонних библиотек)
- `logo.jpg`, `car-*.webp`, `review-*.jpg`, `video-*.mp4`, `poster-*.jpg` — картинки и видео

## Публикация на GitHub Pages

1. Загрузите **содержимое** этой папки в корень репозитория (так, чтобы `index.html` лежал в корне).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Что подключено

- Курс ЦБ (USD, CNY) — загружается автоматически с cbr-xml-daily.ru, обновляется раз в час.
- Яндекс Карта организации — виджет в разделе «Как нас найти».
- Заставка показывается только при первом посещении.
- Форма расчёта: проверяет телефон и открывает выбранный мессенджер (Telegram / MAX) или звонок; текст заявки копируется в буфер обмена.
